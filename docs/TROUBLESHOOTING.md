# 常见问题

## 点击编号后打开系统设置

WindowSnap 缺少设备控制权限。开启权限后重启应用；如果已经开启，请关闭后重新开启。

## Option 拖动没有高亮区域

- 确认设备控制权限已经开启。
- 从窗口顶部标题栏开始拖动。
- 确认 macOS 自带的 Option 拼贴已关闭。
- 对于响应较慢的应用，先单击标题栏使其成为前台窗口。

## 窗口无法放入 7 或 8 列

应用可能具有真实的最小宽度。WindowSnap 会在一次操作中完成多次校正；全部失败后提示未接受目标位置，不会仅凭缩放失败推断真实最小宽度。

## 已经排列的窗口突然消失

先确认当前版本与运行路径，避免使用旧备份。不可见可能来自遮挡、最小化、隐藏、应用行为或桌面空间切换，不能只凭现象认定原因。可查看 `~/Library/Logs/WindowSnap/window-evidence.jsonl` 中目标窗口和已放置窗口的矩形、存在状态及层级。WindowSnap 不会强制跨空间搬移窗口。

## 更新应用后权限失效

本地临时签名版本更新后，macOS 可能把它视为新的可执行文件。请退出 WindowSnap，从辅助功能列表删除旧条目，再添加并开启 `/Applications/WindowSnap.app`，然后重新启动应用。长期解决方案是使用稳定的 Developer ID 签名和 Apple 公证版本。
