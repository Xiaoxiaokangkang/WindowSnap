# WindowSnap V1 使用说明

## 第一次启动

1. 将 `WindowSnap.app` 放入 `/Applications`。
2. 打开应用；它会驻留在菜单栏。
3. 在“系统设置 → 隐私与安全性 → 设备控制与数据访问”中开启 WindowSnap。旧版 macOS 中该分类可能显示为“辅助功能”。
4. 重启 WindowSnap。

更新本地临时签名版本后，如果权限失效，请先从辅助功能列表删除旧的 WindowSnap，再添加并开启新版，然后重新启动应用。

## 4～8 列排列

WindowSnap 会使用显示器的可用区域，自动避开菜单栏和程序坞。

### 可视化面板

先激活目标窗口，再点击菜单栏图标。选择列数后，点击编号即可。

### Option 拖动

按住 `Option` 从标题栏拖动。高亮列就是松开鼠标后的目标区域。

对于响应较慢的应用，WindowSnap 会在一次操作内部多次下发尺寸、等待、读取并校正，不需要再次拖动。窗口身份无法确认时会停止吸附；重试耗尽后提示操作未被接受，不把一次缩放失败直接认定为最小宽度限制。

## 快捷键

- 三分屏第 1～3 列：默认使用 `⌃⌥1`、`⌃⌥2`、`⌃⌥3`。
- 四分屏第 1～4 列：可在设置中自行录入，默认未设置。
- 5～8 列、半屏、四角及其他窗口操作不注册快捷键。

## 超宽屏建议

- 5120×1440 屏幕使用 6 列时，每列约 853～854 点。
- 7、8 列更适合工具窗口、聊天窗口或允许较窄尺寸的应用。
- 排列前应通过调度中心确认所有窗口位于同一个桌面空间。
- 已排列窗口不可见不一定是桌面切换，也可能是遮挡、最小化、隐藏或应用自身行为；可结合本地诊断日志排查。

## 退出和重新打开

- 关闭设置窗口不会退出应用。
- 点击菜单栏图标并选择“退出”才能完全关闭。
- 从“应用程序”再次打开 WindowSnap 会显示设置窗口。

## 版本与本地诊断

- 菜单栏面板和设置窗口显示版本；设置中可查看运行路径。发现旧实例时，可退出本次启动，或确认退出旧实例后使用新版本。
- 本地滚动诊断保存在 `~/Library/Logs/WindowSnap/window-evidence.jsonl`，不记录标题或正文、不自动上传。窗口身份不明确时会安全拒绝吸附；这不代表窗口被锁定。
